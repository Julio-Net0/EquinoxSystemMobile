Desenvolvimento e testes ultrarrápidos em memória sem acoplamento externo

Nenhuma chamada ativa para `expo-sqlite` ou `@supabase/supabase-js`.

Substituição: Estruturas `Map` em memória simulando persistência instantânea.

Sem acionar APIs nativas de Câmera (`expo-camera`) ou GPS (`expo-location`).

Navegação por qualquer tela sem dependência de APIs remotas.

3. Adaptadores & Context API (`AuthContext.tsx`)

Demonstração real do provedor de estado de autenticação global e sessão segura

📄 src/presentation/context/AuthContext.tsx
export const AuthProvider: React.FC<AuthProviderProps> = ({ children, usuarioRepo, sessionStorage }) => { const [usuario, setUsuario] = useState<SessaoUsuarioData | null>(null); useEffect(() => { async function carregarSessao() { const sessaoSalva = await sessionStorage.obterSessao(); if (sessaoSalva) setUsuario(sessaoSalva); } carregarSessao(); }, [sessionStorage]); return ( <AuthContext.Provider value={{ usuario, isAuthenticated: !!usuario }}> {children} </AuthContext.Provider> ); };
🔐 Sessão Segura Encapsulada
  • SessionStorageSecureStore: Wrapper sobre `expo-secure-store`;
  • Hardware Encryption: Persiste os tokens criptografados no Keychain (iOS) e Keystore (Android);
  • Zero Leaking: O domínio e as telas não conhecem os detalhes nativos do sistema operacional.
Código Fonte: Custom Hooks

Demonstração do Custom Hook (`useLeitura.ts`)

A ponte reativa conectando os componentes de UI aos Casos de Uso

📄 src/presentation/hooks/useLeitura.ts
export function useLeitura( leituraRepo: ILeituraRepository, usinaRepo: IUsinaRepository, queueRepo: IActionQueueRepository ): UseLeituraReturn { const [isSubmitting, setIsSubmitting] = useState(false); const [error, setError] = useState<string | null>(null); const registrarLeitura = async (input: RegistrarLeituraInputDTO) => { setIsSubmitting(true); try { const useCase = new RegistrarLeituraUseCase(leituraRepo, usinaRepo, queueRepo); const res = await useCase.executar(input); return res.sucesso; } finally { setIsSubmitting(false); } }; return { isSubmitting, error, registrarLeitura }; }
Custom HookFunção no Código & Casos de Uso
`useAuth()`Consome `AuthContext`, lê `SecureStore` e dispara login/logout.
`useAtividades()`Controla o formulário de atividades e executa `RegistrarAtividadesUseCase`.
`useAvaliacao()`**Orquestra notas de supervisor e auto-avaliação do estudante.
`useAssinatura()`**Coleta a assinatura digital e dispara `AssinarRelatorioUseCase`.
`useRelatorioPdf()`**Valida `podeGerarPdf()` e aciona a geração do relatório em PDF.
`useSyncFila()`**Monitora a fila reativa in-memory (`pending | synced | error`).
